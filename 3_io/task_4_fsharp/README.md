# 3.4. Построение указателя слов с номерами строк на F#

Программа читает текстовый файл и сохраняет алфавитный указатель слов с номерами строк с единицы. Регистр игнорируется. Повторения слова в одной строке дают один номер.

## Запуск

Требуется .NET SDK 7 или новее. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 3_io/task_4_fsharp
New-Item -ItemType Directory -Force build | Out-Null
dotnet fsi main.fsx examples/text.txt build/index.txt
Get-Content -Encoding utf8 build/index.txt
```

Аргументы — входной и выходной текстовые файлы в UTF-8. Слова состоят из букв Unicode и комбинируемых знаков. Цифры и пунктуация разделяют слова. Результат записывается в виде `слово: 1, 3`.
