# 3.1. Внешняя сортировка большого файла на Perl

Программа сортирует целые числа по возрастанию: сохраняет отсортированные фрагменты во временные файлы и попарно сливает их. Входной файл целиком в память не загружается.

## Запуск

Требуется Perl. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 3_io/task_1_perl
New-Item -ItemType Directory -Force build | Out-Null
perl main.pl examples/numbers.txt build/sorted.txt 4096
Get-Content build/sorted.txt
```

Аргументы — входной файл, выходной файл и необязательный лимит числовых данных в памяти в байтах (по умолчанию 1048576, минимум 4096). Во входном файле одно целое число на строку. Длина строки ограничена одной восьмой лимита. До половины лимита отводится под сортируемый фрагмент, остальное — под чтение и сравнение. Служебные структуры интерпретатора учитываются отдельно.
