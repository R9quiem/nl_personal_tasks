# 3.3. Слияние журналов по временным меткам на Lua

Программа последовательно объединяет два отсортированных журнала. Все записи сохраняются. При одинаковых временных метках записи первого файла выводятся раньше записей второго.

## Запуск

Требуется Lua 5.4 или новее. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 3_io/task_3_lua
New-Item -ItemType Directory -Force build | Out-Null
lua54 main.lua examples/first.log examples/second.log build/merged.log
Get-Content build/merged.log
```

Аргументы — два входных журнала и выходной файл. Каждая строка начинается с метки `YYYY-MM-DDTHH:MM:SSZ`, за которой следует пробел и текст события. Входные файлы должны быть упорядочены по возрастанию меток. Некорректные даты и нарушения порядка отклоняются.
