# 3.2. Сравнение бинарных файлов на Ruby

Программа сравнивает два файла блоками по 64 КиБ. При различии выводятся позиция первого отличающегося байта с нуля и размеры файлов. Разная длина также считается различием.

## Запуск

Требуется Ruby. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 3_io/task_2_ruby
ruby main.rb examples/first.txt examples/second.txt
ruby main.rb examples/first.txt examples/first.txt
```

Аргументы — пути к двум файлам любого типа. Первый пример находит отличие на позиции `2`, второй сообщает об идентичности. Код завершения — `0` при совпадении, `1` при различии и `2` при ошибке.
