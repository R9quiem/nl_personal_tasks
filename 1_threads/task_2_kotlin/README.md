# 1.2. Параллельная двумерная свёртка на Kotlin

Программа применяет ядро свёртки к целочисленной матрице, распределяя строки между потоками. Ядро разворачивается на 180°, значения за границами матрицы считаются нулевыми. Размер результата совпадает с размером исходной матрицы.

## Запуск

Требуются JDK 17 или новее и Kotlin/JVM. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 1_threads/task_2_kotlin
New-Item -ItemType Directory -Force build | Out-Null
kotlinc src/Main.kt -include-runtime -d build/convolution.jar
java -jar build/convolution.jar examples/sample.txt 2
```

Первый аргумент — путь к входному файлу, второй — положительное число потоков. Если число потоков не указано, оно определяется автоматически.

Во входном файле задаются высота и ширина матрицы, её элементы, затем высота и ширина ядра и его элементы. Размерности ядра должны быть положительными и нечётными. Значения разделяются пробельными символами.
