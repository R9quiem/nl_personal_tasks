# 1.2. Параллельная двумерная свёртка на Kotlin

Программа применяет ядро свёртки к целочисленной матрице. Ядро разворачивается на 180°, за границами матрицы значения считаются нулевыми. Размер результата совпадает с размером исходной матрицы.

## Запуск в PowerShell

Нужны JDK и компилятор Kotlin/JVM (`kotlinc`). Из корня репозитория выполните:

```powershell
cd 1_threads/task_2_kotlin
New-Item -ItemType Directory -Force build | Out-Null
kotlinc src/Main.kt -include-runtime -d build/convolution.jar
java -jar build/convolution.jar examples/sample.txt 2
```

Если компилятор распакован отдельно, вызовите `kotlinc.bat` по полному пути вместо `kotlinc`. Второй аргумент задаёт число рабочих потоков. По умолчанию программа использует число доступных JVM процессоров. Потоков создаётся максимум по числу строк.

## Формат входного файла

Сначала идут высота и ширина матрицы, затем её элементы по строкам. После них идут высота и ширина ядра и его элементы. Все значения разделяются пробельными символами. Элементы — знаковые 32-битные целые числа. Обе размерности ядра должны быть положительными и нечётными. Для сумм используется `BigInteger`, чтобы сохранить точность при больших значениях.

В `examples/sample.txt` ядро асимметрично. После поворота его средняя строка из `1 2 0` превращается в `0 2 1`. Каждый элемент результата равен удвоенному исходному элементу плюс его сосед справа. В последнем столбце вклад соседа равен нулю.

```text
4 7 10 8
16 19 22 16
28 31 34 24
```

## Как устроено распараллеливание

- `convolve` делит строки результата на диапазоны. Для трёх строк и двух потоков это `[0, 2)` и `[2, 3)`.
- `convolveRow` перебирает коэффициенты ядра для каждого элемента строки. Индексы коэффициентов берутся с обоих концов в обратном порядке, что даёт поворот на 180°. Координаты за пределами матрицы пропускаются.
- Потоки читают общую матрицу и ядро, а каждый записывает только свои строки результата. После завершения задач главный поток печатает строки в исходном порядке.

## Демонстрация для видео

Покажите асимметричное ядро и вручную посчитайте левый верхний элемент `2 × 1 + 2 = 4` и правый верхний элемент `2 × 4 + 0 = 8`. Затем покажите деление строк в `convolve` и сравните результаты двух запусков:

```powershell
$single = java -jar build/convolution.jar examples/sample.txt 1
$parallel = java -jar build/convolution.jar examples/sample.txt 2
$parallel
($single -join "`n") -ceq ($parallel -join "`n")
```

Последняя команда должна вывести `True`.
