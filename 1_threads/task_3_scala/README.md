# 1.3. Параллельный поиск самого длинного возрастающего участка на Scala

Программа параллельно находит самый длинный непрерывный строго возрастающий участок массива с учётом границ фрагментов. Выводятся длина, начальный и конечный индексы с нуля. При равной длине выбирается самый левый участок.

## Запуск

Требуются Scala CLI и JDK 17 или новее. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 1_threads/task_3_scala
scala-cli run Main.scala --server=false --jvm system -- examples/sample.txt 2
```

Первый аргумент — путь к текстовому файлу с целыми числами, разделёнными пробельными символами. Второй — положительное число потоков. Если число потоков не указано, оно определяется автоматически.
