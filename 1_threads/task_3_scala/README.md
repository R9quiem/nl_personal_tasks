# 1.3. Параллельный поиск самого длинного возрастающего участка на Scala

На входе текстовый файл со знаковыми 32-битными целыми числами, разделёнными пробелами или переводами строк. Программа выводит длину и индексы самого длинного непрерывного строго возрастающего участка. Индексы начинаются с нуля, конечный индекс включён. При равной длине выбирается самый левый участок. Для пустого файла выводится `length=0 start=-1 end=-1`.

## Запуск

Нужны Scala CLI и JDK 17 или новее. Из корня репозитория:

```powershell
cd 1_threads/task_3_scala
scala-cli run Main.scala --server=false --jvm system -- examples/sample.txt 2
```

Если Scala CLI распакован отдельно, вместо `scala-cli` вызовите его по полному пути через `&`. Последний аргумент задаёт число потоков. По умолчанию используется число доступных процессоров, максимум по одному рабочему потоку на элемент.

На этом компьютере Scala CLI распакован в `%LOCALAPPDATA%\npl-labs-tools\scala-cli-1.19.0`. Из папки лабораторной можно запустить пример так:

```powershell
$scalaCli = Join-Path $env:LOCALAPPDATA 'npl-labs-tools\scala-cli-1.19.0\scala-cli.exe'
$env:COURSIER_REPOSITORIES = 'https://repo.maven.apache.org/maven2'
& $scalaCli run Main.scala --server=false --jvm system -- examples/sample.txt 2
```

## Как работает программа

- `longestRun` делит массив на непересекающиеся фрагменты и отправляет их в пул потоков.
- `scan` проходит по своему фрагменту один раз. Он возвращает лучший участок и длины возрастающих участков, которые начинаются у левого края и заканчиваются у правого края.
- `merge` объединяет соседние фрагменты слева направо. Если последний элемент слева меньше первого элемента справа, можно соединить правый край левого фрагмента с левым краем правого. Когда один из фрагментов целиком возрастает, его длина входит в обновлённую длину края. Благодаря этому следующий шаг может продолжить участок через несколько границ.

## Демонстрация для видео

Покажите массив `8 1 3 5 7 2`. При двух потоках фрагменты будут `[8, 1, 3]` и `[5, 7, 2]`. На границе `3 < 5`, поэтому получаем общий участок `[1, 3, 5, 7]`.

```powershell
scala-cli run Main.scala --server=false --jvm system -- examples/sample.txt 1
scala-cli run Main.scala --server=false --jvm system -- examples/sample.txt 2
scala-cli run Main.scala --server=false --jvm system -- examples/sample.txt 3
```

Во всех случаях результат — `length=4 start=1 end=4`. При трёх потоках этот участок проходит через две границы.
