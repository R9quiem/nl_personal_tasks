# 1.1. Параллельное построение гистограммы байтов на Rust

Программа подсчитывает частоты всех 256 значений байта в бинарном файле. Вывод содержит 256 строк вида `FF: 2`, включая байты с нулевой частотой. Используется стандартная библиотека Rust.

## Запуск

Из корня репозитория перейдите в `1_threads/task_1_rust`. Нужен Rust 1.74 или новее.

```powershell
cd 1_threads/task_1_rust
cargo run --release -- "путь к файлу.bin" 4
```

Второй аргумент задаёт число рабочих потоков и должен быть положительным целым. Если его опустить, программа возьмёт значение, возвращаемое `available_parallelism()`. Для файла короче запрошенного числа потоков создаётся по одному потоку на байт. Для пустого файла выводятся 256 нулевых частот.

## Как работает программа

1. `histogram` узнаёт размер файла и делит его на непересекающиеся диапазоны. Первые потоки получают по одному дополнительному байту, если размер файла делится с остатком. Например, пять байтов на три потока делятся на диапазоны `[0, 2)`, `[2, 4)`, `[4, 5)`.
2. Каждый поток выполняет `count_range`: открывает файл, переходит к началу своего диапазона и читает только его блоками до 64 КиБ. Частоты записываются в собственный массив `[u64; 256]`.
3. Главный поток получает массивы через `join()` и складывает счётчики по индексам. Поскольку каждый байт попадает ровно в один диапазон, число потоков не меняет итог.

## Демонстрация в PowerShell

Создайте файл из байтов `00 FF 00 41 FF` и посмотрите его содержимое.

```powershell
[IO.File]::WriteAllBytes((Join-Path $PWD.Path 'sample.bin'), [byte[]](0, 255, 0, 65, 255))
Format-Hex -Path .\sample.bin
$single = cargo run --quiet --release -- .\sample.bin 1
$parallel = cargo run --quiet --release -- .\sample.bin 3
($single -join "`n") -ceq ($parallel -join "`n")
$parallel.Count
$parallel | Select-String '^(00|41|FF):'
```

Ожидается `True`, затем `256` и строки `00: 2`, `41: 1`, `FF: 2`.

Для короткого видео покажите входной файл, затем в `histogram` объясните деление пяти байтов между тремя потоками. В `count_range` покажите локальные счётчики, а в `histogram` — как результаты складываются после `join()`. Завершите сравнением вывода для одного и трёх потоков.
