# 1.1. Параллельное построение гистограммы байтов на Rust

Программа параллельно подсчитывает частоты всех 256 значений байта в бинарном файле и выводит итоговую гистограмму.

## Запуск

Требуется Rust 1.74 или новее. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 1_threads/task_1_rust
cargo run --release -- "input.bin" 4
```

Первый аргумент — путь к бинарному файлу, второй — положительное число потоков. Если число потоков не указано, оно определяется автоматически.
