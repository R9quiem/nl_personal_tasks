# 2.4. Проверка изоморфизма деревьев на Julia

Программа рекурсивно сравнивает структуру двух корневых бинарных деревьев без значений в узлах. Для каждого узла учитываются исходный и переставленный порядки потомков.

## Запуск

Требуется Julia. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 2_algorithms/task_4_julia
julia main.jl examples/isomorphic.txt
julia main.jl examples/different.txt
```

Аргумент — путь к файлу с двумя деревьями. Пустое дерево обозначается точкой `.`, узел — `(левое,правое)`. Лист записывается как `(.,.)`. Пробельные символы игнорируются. Примеры выводят `Isomorphic` и `Not isomorphic` соответственно.
