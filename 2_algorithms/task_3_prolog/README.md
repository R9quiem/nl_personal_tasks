# 2.3. Поиск эйлерова пути в ориентированном графе на Prolog

Программа рекурсивным алгоритмом Хиерхольцера находит путь, проходящий по каждому направленному ребру ровно один раз. Поддерживаются циклы и повторяющиеся рёбра. Если пути нет, выводится сообщение.

## Запуск

Требуется SWI-Prolog. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd 2_algorithms/task_3_prolog
swipl -q -s main.pl -- examples/sample.txt
```

Аргумент — путь к файлу со списком направленных рёбер вида `[(a,b),(b,c)].`. Вершины задаются атомами Prolog или целыми числами. Точка в конце обязательна. Для примера выводится `[a,b,a,b,c]`.
